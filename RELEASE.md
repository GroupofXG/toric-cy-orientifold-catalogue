# Favourable toric Calabi–Yau orientifolds at h¹,¹ = 1–6

This edition covers 22,974 favourable polytopes, 646,903 FRSTs and 19,464,170 eigenfamily records, including both polynomial characters. The reflection calculation includes the nonzero lattice classes realised by coordinate signs.

- [Browse the catalogue](https://groupofxg.github.io/toric-cy-orientifold-catalogue/). Paste a polytope, FRST or eigenfamily ID to open the associated records. The page can export the selected FRST with its actions and families as JSON.
- [Read the field guide](https://groupofxg.github.io/toric-cy-orientifold-catalogue/guide.html). The public data retain the four JSON Lines tables and the identifiers in Appendix A. Each rank download includes the symbolic coefficient definitions.
- For a local analysis, choose the `h11-N-four-tables.zip` asset for the desired rank. Verify the downloaded file against `SHA256SUMS.txt`. The additional `catalogue-pages-data.zip` contains the indexed batches used by the web reader.

In this snapshot 3,602 nonempty eigenfamilies have a null smoothness verdict. Citation and field definitions are in the accompanying paper by Xu Cao and Xin Gao. [arXiv:2611.22785](https://arxiv.org/abs/2611.22785)
