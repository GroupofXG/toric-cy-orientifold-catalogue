# Toric Calabi–Yau Orientifold Catalogue

This repository accompanies **Toric Calabi–Yau orientifolds: constructions, fixed loci and O-plane charges** by Xu Cao and Xin Gao. [arXiv:2611.22785](https://arxiv.org/abs/2611.22785)

## Data release

The catalogue update is in progress. The data will be posted here once the calculations are complete.

The catalogue records which involutions are supported by each triangulation and the fixed loci on the associated invariant hypersurfaces. For each Hodge number $h^{1,1}$, the planned JSON Lines files are `polytopes.jsonl`, `triangulations.jsonl`, `involutions.jsonl`, and `orientifolds.jsonl`. Appendix A describes the fields and gives example records. [Database format](https://arxiv.org/html/2611.22785v1#A1)

## Original catalogue

The original divisor-exchange (`NID`) and coordinate-reflection (`REF`) data remain available in [GroupofXG/anewcydatabase](https://github.com/GroupofXG/anewcydatabase) and its [data-v1 release](https://github.com/GroupofXG/anewcydatabase/releases/tag/data-v1). For work using those files, cite the original catalogue paper by Xu Cao, Hongfei Gao, and Xin Gao, [JHEP 10 (2024) 188](https://doi.org/10.1007/JHEP10(2024)188).
