# Rank-seven catalogue reader data

These per-batch files supply the [catalogue reader](https://groupofxg.github.io/toric-cy-orientifold-catalogue/?search=1&rank=7). The original four JSON Lines tables and coefficient definitions are available in the [rank-seven release](https://github.com/GroupofXG/toric-cy-orientifold-catalogue/releases/tag/h7-20261122). The reader checks the SHA-256 digest of each batch before decoding it. The website pins a complete edition by commit.
